How the site works.

AutoImage combines prompt writing, optional language tools, image models, and a searchable gallery. This guide explains what each control changes and what happens after you press Start.

00

Overview

The basic loop is deliberately short: describe an image, choose how much assistance and automation you want, generate, then review the result in the same workspace.

Prompt
The written instruction sent to the selected image model. It can be concise or highly specific.
Generation
One model request that produces an image. Automated runs repeat this request up to the maximum you set.
Result
A saved image with its prompt, model, visibility, tags, rating, and creation information.
01

Create an image

Start with the controls at the top of the home page. You can keep the process manual or let AutoImage repeat and vary the work for you.

Write the prompt

Enter the subject, setting, style, lighting, composition, or mood you want. Clear nouns and concrete visual details usually give the model more to work with than abstract instructions alone.

Choose assistance

Turn on Enhance when you want the site to expand the prompt before generation. Leave it off when exact wording matters.

Set repetition

Turn on Auto to continue generating without pressing Start for every image. The adjacent maximum limits the run from 1 to 10 generations.

Press Start

The request is validated, sent to the selected model, and added to the gallery when complete. The generation may stop early if the maximum is reached, credits are unavailable, or a provider returns an error.

02

Prompt tools

Prompt tools change the text before it reaches the image model. Use them intentionally: they are useful for exploration, but they make the final instruction less literal.

Variables
Variable markers use the form ${term}. They allow the prompt system to substitute related terms and create variations across an automated run.
A ${cat} in ${style} art, soft window light
Enhance
Enhancement expands a short instruction into a more descriptive prompt. AutoImage retains the relationship between the original and enhanced text so the result can still be understood later.
Magic prompt
The wand control helps develop the current prompt. Treat the output as an editable draft rather than a required format.
Mixup & mashup
These drawer settings introduce additional combinations or style blending. They are exploratory controls; turn them off when repeatability matters.
Multiplier text
Reusable enhancement text can add a consistent direction across generations—for example, a preferred photographic treatment or production constraint.
For reproducible work: disable Enhance, Mixup, and Mashup; use a fixed prompt; select one model; and generate one image at a time.
03

Models & settings

The drawer contains model choices and generation defaults. Different models interpret the same words differently, so model selection is part of the creative decision rather than a quality switch.

Models
Select the providers or models available to your account. Availability and generation cost can change; the current interface and billing page are the source of truth.
Auto Public
When enabled, newly generated images are made public automatically. Leave it disabled when work should remain in your private library.
Auto Download
Downloads each completed image to your device in addition to saving it to the site.
Theme
Changes the workspace appearance only. Theme selection does not alter the generated image or prompt.
04

Your image library

Generated images remain in the gallery, where they can be viewed, organized, searched, and separated by ownership. The gallery loads additional results as you move through it.

Public & private
Public shows images shared with everyone. Private shows images belonging to the signed-in account, including work that has not been published.
Views
Compact, List, and Full change how much image and prompt information appears at once. They do not change the underlying result set.
Search
Search checks prompt text and searchable metadata, ranks the complete visible result set, and loads ranked pages as you continue through the gallery. Owner and tag selections travel with the search request.
Tags & ratings
Tags provide reusable organization and can narrow the feed or search. Ratings are stored with an image and help distinguish preferred results.
Profiles
Public profile pages expose public images only. Private images remain restricted to their owner.
Search is contextual. If an expected image is absent, first confirm the Public or Private selection and remove any active tag filters. Those choices define which images the server may return.
05

Accounts & credits

An account connects generation history, private images, credits, and billing. Public browsing is broader, but private creation history is always tied to the authenticated user.

Credit balance
The header displays the current balance when available. Each image request uses credits according to its model and settings.
Billing
The Account page contains credit purchases, transaction information, and image-generation history associated with billing.
Authentication
Sign in to generate against your account, see private images, and retain ownership controls. If a session expires, sign in again before retrying a private operation.
06

Common questions

Why did the site create more than one image?

Auto was enabled. Turn it off for a single request, or lower the adjacent maximum to reduce the number of generations in an automated run.

Why is the final prompt different from what I typed?

Enhance, Magic Prompt, Mixup, Mashup, multiplier text, or variable substitution may have changed the instruction before generation. Disable those tools when exact wording matters.

Why can’t I find an image I generated?

Check whether the gallery is showing Public or Private images, then remove active tag and search filters. A private image will not appear in the public feed or on a public profile.

Why did an automated run stop?

The configured maximum may have been reached, the account may need credits, the session may have expired, or the selected provider may have returned an error. Check the page notification and header balance before retrying.

How do I keep new work private?

Leave Auto Public disabled. After generation, confirm the image appears under the Private owner selection before sharing it.

Does changing the gallery view regenerate an image?

No. Compact, List, and Full are presentation modes for the same saved image and metadata.

How do I download every generated result?

Enable Auto Download in the drawer before starting the run. Your browser’s download settings may still ask for permission when several files are created.

The fastest way to understand the controls is to begin with one prompt, one model, and one generation—then add automation deliberately.
